# Logos

uzbtrust logosi: bir tekis ko‘k yulduz, rangi `#0071E3`, fon shaffof. Ikkala fayl bir xil piksellardan iborat.

- `uzbtrust-logo.png` — 2560×2560, atrofida bo‘sh joy bilan: ilova ikonkasi, favicon, avatar, ijtimoiy tarmoq.
- `uzbtrust-star.png` — 1400×1346, bo‘sh joyi qirqilgan: wordmark (yulduz + «uzbtrust»), hujjat sarlavhasi, matn yonida.

Rang qorong‘u fonda ham o‘zgarmaydi. Ko‘k yoki rangli fon ustiga qo‘yilmaydi. Hozircha faqat PNG; vektor (SVG) varianti qo‘shilsa, u asosiy fayl bo‘ladi.
