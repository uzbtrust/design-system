# Logos

uzbtrust logosi: bir tekis ko‘k yulduz, rangi `#0071E3`, fon shaffof. Asosiy fayl — SVG (vektor, bitta `<path>`), PNG — zaxira. Hamma fayllarda shakl bir xil.

- `uzbtrust-logo.svg` — viewBox 2560×2560, atrofida bo‘sh joy bilan: ilova ikonkasi, favicon, avatar, ijtimoiy tarmoq.
- `uzbtrust-star.svg` — viewBox 1400×1346, bo‘sh joyi qirqilgan: wordmark (yulduz + «uzbtrust»), hujjat sarlavhasi, matn yonida.
- `uzbtrust-logo.png` (2560×2560), `uzbtrust-star.png` (1400×1346) — zaxira: faqat SVG qabul qilinmaydigan joyda (ba’zi ijtimoiy tarmoqlar, ilova do‘konlari, ofis dasturlari).

SVG'lar PNG'dan avtomatik izlab olingan, qo‘lda chizilmagan: kontur 50% shaffoflik chegarasidan olinib, 8× kattalashtirishdan qolgan tishlar tekislangan va kubik egri chiziqlarga o‘tkazilgan. PNG o‘lchamida rasterlab solishtirilganda alpha maskalar 99.8% mos (IoU 0.998). SVG'ni tahrirlamang va shaklini o‘zgartirmang.

Rang qorong‘u fonda ham o‘zgarmaydi. Ko‘k yoki rangli fon ustiga qo‘yilmaydi.
