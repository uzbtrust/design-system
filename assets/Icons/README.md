# Icons

Lucide 0.577.0 to‘plamidan 43 ta ikon, aynan nusxa: 24×24 viewBox, chiziq qalinligi 2, uchlari va burchaklari yumaloq.

- Fayllarda chiziq rangi #6e6e73 (`fg-3`) — ikkala mavzuda ham ko‘rinsin deb. Kodda `stroke="currentColor"` va `stroke-width="1.75"` qo‘ying (matnning oddiy og‘irligiga mos) va rangni matn rangidan oling (`fg-2`, `fg-3`, faol holatda `accent-ink`).
- O‘lcham: tugma va ro‘yxatda 16–18px, kichik meta ikonlari 13px (chiziq 1.8), bo‘sh holat 28px (chiziq 1.8).
- Litsenziya: ISC (`LICENSE`, shu papkada).
- Kerakli ikon bu yerda bo‘lmasa, Lucide'dan xuddi shu parametrlar bilan oling. Boshqa ikon to‘plamini aralashtirmang.
