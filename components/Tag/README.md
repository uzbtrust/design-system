# Tag

Kichik pill yorliqlar: holat, muhimlik, son va muddat.

## Tuzilma
```html
<span class="tag tag-warn">Muhim</span>
<span class="count-chip is-full"><svg …/> 3/3</span>
<span class="due due-bad"><svg …/> 2 kun kechikdi</span>
```

## Variantlar
- `tag` — 12px/600, oddiy harflarda, `track-caption`; `chip` fon, `fg-2`. Rangli: `tag-accent` / `tag-done` (`accent-soft` + `accent-ink`), `tag-warn` (`warn-soft` + `warn`), `tag-bad` (`bad-soft` + `bad`). Muhimlik: `tag-priority-2` = warn, `tag-priority-3` = bad.
- `count-chip` — son va ikon, `tabular-nums`; to‘lganda `is-full` (ko‘k).
- `role-pill` — rol nomi, bosh harfsiz.
- `due` — muddat: oddiy `fg-3`, `due-warn` (bugun), `due-bad` (kechikkan, 500).

## Qoidalar
Rang doim so‘z bilan birga keladi. Teg ichida bir-ikki so‘z, ortiq emas.
