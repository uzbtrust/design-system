# Empty

Bo‘sh holat: ikon, qisqa sarlavha, bir jumla va bitta amal.

## Tuzilma
```html
<div class="empty">
  <span class="empty-icon"><svg …/></span>
  <h2>Hozircha bo‘sh</h2>
  <p>Nima uchun bo‘sh va qanday to‘ladi.</p>
  <button class="btn btn-secondary">Bitta amal</button>
</div>
```

## Qoidalar
- Yuza `card`, `r-xl`, markazda. Ikon doirasi 64px, `bg` fon, `accent-ink` ikon, `shadow-sm`.
- Sarlavha `--fs-h3`/600; matn `fg-3`, eni 30em.
- `empty-quiet` — ichki bo‘limlar uchun kichikroq variant (amalsiz).
- Matn ayblamaydi va kelajakni aytadi: «… shu yerda paydo bo‘ladi».
